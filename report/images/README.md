# 实验截图存放处

此目录**不包含任何伪造或示意截图**。请用你在自己的设备和 GitHub 账号中真实完成的操作，生成以下图片（png 格式）。

| 文件名 | 截图内容 |
| --- | --- |
| `01-repository.png` | 个人仓库首页；需看到 Owner、仓库名和 Public |
| `02-structure.png` | 项目文件树和 `mkdocs.yml` |
| `03-local-build.png` | 本地 `build --strict` 成功记录或页面预览 |
| `04-pages-settings.png` | Pages 的 Source 选择 GitHub Actions |
| `05-actions-first.png` | 首次 Actions `build`、`deploy` 成功 |
| `06-site.png` | 公开网页，保留浏览器地址栏 |
| `07-second-actions.png` | 第二次 push 触发的 Actions 成功记录 |
| `08-updated-site.png` | 刷新后站点显示第二次新增文字 |

所有截图应是本人实际操作记录。报告已经引用这些文件名，上传后图片会自动显示；上传前的断图表示任务尚未完成，不能作为最终作业提交。
